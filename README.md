
#### 👤 Whoami

I am a **Cybersecurity Student** and **Linux enthusiast** based in Ethiopia. I have a deep passion for exploring systems architecture, networking, and automation. 

My primary goal is to build reliable tools that streamline day-to-day operations and customize environments, while continually deepening my understanding of modern security patterns and vulnerabilities. 

When I'm not at the keyboard, I'm usually testing new minimal Linux setups or trying to optimize my workflow for maximum performance.

**Current Projects:**
- **[masu-hyprland-installer](https://github.com/Maty156/masu-hyprland-installer)**: Automated installer for Hyprland featuring Catppuccin theme integration.
- **[masu-terminal-installer](https://github.com/Maty156/masu-terminal-installer)**: A streamlined configuration tool for ZSH and Powerlevel10k built for both Linux and Termux.
- **[portfolio](https://github.com/Maty156/portfolio)**: Personal web presence built from scratch with clean semantics.
